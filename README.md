# blessed-practices

Blessed code practices.

- **`general/`** — adopted practices. Short prose, one topic per file.
- **`candidates/`** — an [Open Knowledge Format](https://okf.md) bundle of
  proposals under review, each carrying the evidence it was derived from.
  Start at [`candidates/index.md`](candidates/index.md).

Candidates carry `status: draft`. Adopting one means flipping it to `stable`
with a `verified` entry naming who accepted it and when; rejecting one means
deleting it with a line in `candidates/log.md` saying why.
